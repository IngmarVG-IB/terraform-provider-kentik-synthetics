# Kentik Synthetics provider

The Kentik Synthetics provider manages [Kentik synthetic monitoring](https://kb.kentik.com/v4/Ma00.htm):
synthetic tests of every type supported by the API, private agents and offline-agent alerts.

It uses the Kentik v6 gRPC API, `kentik.synthetics.v202309`, at `grpc.api.kentik.com:443`
(`grpc.api.kentik.eu:443` for the EU cluster).

-> **Upgrading from 0.2.x?** The provider moved from the beta API (v202101beta1) to v202309. Existing
configurations keep working, with deprecation warnings. See the
[upgrade guide](https://github.com/kentik/terraform-provider-kentik-synthetics/blob/master/docs/UPGRADING.md).

## Example usage

```terraform
terraform {
  required_providers {
    kentik-synthetics = {
      source  = "kentik/kentik-synthetics"
      version = ">= 0.3.0"
    }
  }
}

provider "kentik-synthetics" {
  # Required. Can also be set with KTAPI_AUTH_EMAIL / KTAPI_AUTH_TOKEN; prefer the environment for the token.
  email = "john@example.com"
  token = var.kentik_token

  # Optional. US cluster (grpc.api.kentik.com:443) by default; "EU" selects grpc.api.kentik.eu:443.
  region = "US"

  # Optional retry of transient API errors (UNAVAILABLE, RESOURCE_EXHAUSTED).
  retry {
    max_attempts = 5
    min_delay    = "1s"
    max_delay    = "30s"
  }
}

variable "kentik_token" {
  type      = string
  sensitive = true
}
```

Credentials can also come from the environment:

```shell
export KTAPI_AUTH_EMAIL="john@example.com"
export KTAPI_AUTH_TOKEN="..."
```
